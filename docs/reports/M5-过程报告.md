## 一、这阶段做了什么

1. **两张新表**（`memory_facts` / `quiz_records`，create_all 自动建、零迁移）；
2. **错题本**：`POST /chat/score` 判分即落库——**全部作答入 quiz_records**（错题本按 is_correct 过滤、周报算正确率），**答错的**另生成零 LLM 的薄弱记忆并双写；响应新增 `recorded`（记入错题数），前端判分后即时提示去向；
3. **长效记忆双写**：MySQL=事实源，Chroma `u{id}mem`=语义索引；**先事实后索引**（索引挂了只丢聪明度不丢记忆）；召回 = 语义 top ∪ 最近条，**任何失败降级最近条**，无记忆快路零开销；
4. **个性化注入**：每次答疑/出题前召回记忆 → prompt 增【学情背景】段（`MEMORY_TOP_K=5` 上限、单条 150 字、**明令禁复述**护栏）——零新增模型调用；
5. **学习周报**（M5 唯一新增 LLM 调用点，按钮触发）：聚合近期对话+答题记录+**图谱关联素材** → LLM 输出 `{report, weak_points}` → 报告(kind=report)与薄弱点(kind=weak_point)双双入库；解析失败 502 绝不给假报告；
6. **动态知识点图谱**（`app/memory/knowledge_graph.py`，产品经理点名动态化）：
   - **派生现算、不存边表**——节点=documents 表文件名解析（编号/合并编号/无编号三档），语义边=存量块向量查询（**零 Ollama 调用**），新上传文档下次打开列表自动入图、删除自动出图；
   - 结构边：父（2.3.2→2.3「前置基础」）+ 前序兄弟（2.3.2→2.3.1「同章相邻」）；
   - 错题列表每题附 `related` 推荐，前端「**去问一问**」按钮跳答疑页注入追问（pending_prompt 同款机制）；
7. **新路由**：`/quiz/records`（列表带图谱推荐/删除）、`/memory/report`（生成/最近）、`/memory/facts`；新页面「**错题与学情**」（第三导航页）：周报 + 错题本 + 关联推荐 + 记忆清单。

**红线自查**：新增 LLM 调用仅周报一处（按钮触发、串行过闸门）；注入/错题/图谱全零调用；语义近邻用存量向量连 embedding 都不打。

## 二、遇到了什么问题

1. `score_quiz` 只回总分没有逐题对错——错题本按题落库缺数据源；
2. 判分提示词同步升级后，既有混合判分测试的桩缺 `correct` 数组（预期红）；
3. 章节解析正则漏了 `~`/`+` 分隔符——合并编号（3.4.1~3.4.4）整节被降级成无编号文件节点；剥码后标题残留合并尾巴（`3.4.4_特殊矩阵…`）；
4. 图谱模块一度私自开数据库会话（SessionLocal）——分层越界；
5. `chat.py` 里写出了 `__import__(...)` 动态导入丑代码；
6. Python 3.11 f-string 不支持嵌套同引号（`{x or "默认"}` 直接 SyntaxError）；
7. config.py 与 .env.example 的编辑锚文本与实际不符（上次编辑顺序导致措辞漂移），Edit 失配。

## 三、怎么解决的问题（与上一一对应）

1. 判分输出升级为逐题 `details`（单选=代码确定、简答=LLM `correct[]` 数组，按原题序对齐）；**解析失败不落库**（没判明白就不记录，防脏数据）；
2. 测试桩补 `correct:[true]` 并加 `details` 逐题断言——测试随契约演进而红是正常节奏，改桩不改语义；
3. 分隔符白名单补 `~+`，标题再剥一层 `^\d+(\.\d+)*[_\-\s~+]*`；用 `3.4.1~3.4.4` 与 `3.3.4+3.3.5` 实测断言锁死；
4. 改为调用方（api 层，本就持有 db）传入 `file_names/group_ids`——图谱是纯计算库，不碰会话生命周期；
5. 顶部既有 long_term 导入直接加 `make_weak_fact`，删掉动态导入；
6. 先把值赋给局部变量再进 f-string（3.11 兼容写法）；
7. grep 定位实际锚文本后重试（编辑前先读实况，M4 以来第三次验证这条纪律）。

**真机冒烟**（走产品经理正运行的服务）：判分 `recorded=1` → 错题本 1 条带教材锚 → 图谱推荐实时算出 `2.3.2_3_单链表的建立（0.91）`、`2.3.2_2_单链表的查找（0.89）` 两条语义近邻——动态图谱在真实课件上首跑即中。

**遗留/边界**：周报的 LLM 提炼质量受 7B 限制（模板字段已固定，可多试几次对比）；「知识点关联推荐」在错题无教材锚时退化为全局结构边（前端提示语已含出处字段）；跨课程全局图谱、人工维护边属明确不做。
