## 一、这阶段做了什么

1. **统计层** `app/monitoring/stats.py`：只读既有表的聚合函数（提问量/近 7 天趋势/命中率/兜底率/高频课件/答题表现/知识库概览），`now` 可注入方便测试固定时钟；**不建 qa_logs/retrieval_logs 新日志表**——messages 表本就是结构化问答日志、回答的 sources 即检索结果落库形态，再建表是双写冗余且历史数据不可见（ROADMAP 目录树与计划变更记录已同步改口径）；
2. **接口层** `GET /monitoring/overview`：鉴权 + user_id 隔离，聚合逻辑全部在 stats 层（api 薄、能力厚的分层纪律）；
3. **看板页**（第四导航页「数据看板」）：`st.metric` 指标卡 + 7 天柱状图（pandas 为 Streamlit 自带依赖，零新增 requirements）；页面零计算、打开即出图；
4. **演示脚本全流程版**：`demo_e2e.py` 从 6 项检查扩到 17 项——注册→建组→上传→会话→正例→负例→会话回看→**出题（真 LLM）**→判分（自带固定卷保确定性）→错题本→**看板对账 3 项**；出题赌真 LLM、判分/对账零随机性是刻意分层（现场要演示的必须验，能确定的不赌生成）；
5. **README 定稿**：收编产品经理手改（快速开始措辞 + 评估集 6 个真实擦边负例入库）、简介补数据看板；
6. **修复 M4 遗留缺陷（详见下）**：滑窗改写剔除兜底轮历史；
7. ROADMAP：M6 标 ✅、验收列回填、计划变更记录补两行（日志表决策 + M6 完成）。

**红线自查**：看板/统计只读 MySQL，零 LLM/OCR/embedding 调用；演示脚本仍串行单请求（每步等上一步完成）。

## 二、遇到了什么问题

1. **单测 `top_files` 并列排序断言错**：同为 1 次的两个文件，实现按文件名码点升序（「旧」U+65E7 < 「课」U+8BFE），断言按想当然的语义顺序写；
2. **★demo 出题翻车（M4 遗留真 bug）**：`正例 → 负例(番茄炒蛋) → 出题` 序列中，出题这轮空召回走兜底、intent 掉回 qa，且**连续多轮持续翻车**——同样的出题指令在无负例的会话里完全正常；
3. **demo 判分断言错在自己的测试数据**：`FIXED_ANSWERS = ["A", "B"]` 与标准答案完全一致 → 全对 100 分、recorded=0，与「故意答错一题」的设计意图相反；
4. 复现脚本第一版密码两次 `token_urlsafe` 不同导致登录 KeyError（一次性笔误）；
5. ROADMAP 目录树 Edit 锚文本空格数与实际不符再次失配（M5 报告已记录过的同款纪律问题）。

## 三、怎么解决的问题（与上一一对应）

1. 修正断言为码点升序并在注释里写明「确定性字典序才是可复现契约」——实现不动，契约讲清楚；
2. **两组对照复现钉死根因**（全程走 HTTP 经服务端互斥锁，不另开 Ollama 客户端）：
   - 对照 A（正例 → 出题）：出题 `hit=True, intent=quiz` 三次全命中；
   - 对照 B（正例 → 负例 → 出题）：出题 `hit=False` 持续空召回。
   根因 = 滑窗历史里 hit=false 的兜底轮把 query 改写带偏：拒答话术零语义信息，其用户问题（「番茄炒蛋」）却是强污染话题，改写 LLM 被带偏后检索必空，且污染随窗口持续多轮。
   **修复**（`short_term.load_window`）：兜底轮**问答成对剔除**（只删回答没用，问题文本照样带偏）、**先过滤后截窗**（N 变为「最近 N 条有效消息」，夹几轮兜底也不把更早的实质对话挤出窗口）；全兜底会话剔除后为空 → 改写零调用快路保持。新增 2 项单测锁死（含提问连坐断言），修复后 demo 重跑出题项 PASS；
3. 答案改 `["A", "A"]`（第 2 题标准答案 B）→ 恰好 1 对 1 错，score=50、recorded=1；
4. 密码改单次生成赋变量复用；
5. 先 grep 拿精确锚文本再 Edit（纪律第三次验证生效）。

**真机验证**（产品经理正运行的服务，`uvicorn --reload` 热载修复）：`python scripts/demo_e2e.py` → **17/17 ALL PASS**，含看板对账三项精确值：提问 3、命中 2、兜底 1、答题 2 条错 1、top_files 含演示课件——「跑问答看板对账」验收达标（全量单测另测趋势窗口/越权隔离/零数据除零保护）。

**遗留/边界**：改写污染的修复只作用于滑窗历史；周报素材（`collect_report_materials` 取最近 40 条对话）仍含兜底轮——周报是 LLM 提炼全局学情，拒答轮占少量比例、不构成改写式带偏，明确不做。看板口径为「本人全量 + 近 7 天趋势」，时间范围参数化（自定义区间查询）超演示体量需求，明确不做。
